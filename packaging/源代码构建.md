# Anllm 1.4 源代码构建

运行安装版或便携版不需要以下开发环境。源码构建使用 Windows x64、Python 3.11.9，以及 `requirements-build.txt` 中固定版本的依赖。

1. 在解压后的 `Anllm` 目录创建 Python 虚拟环境，并安装依赖。
2. 先运行 `python -c "import comtypes.client; comtypes.client.GetModule('UIAutomationCore.dll')"` 生成 Windows UI Automation 接口，再切换到 `packaging` 目录。每次打包先运行 `python generate_icon.py`，将实际应用图标编译成 16–256px 的白金多尺寸 ICO，然后运行 `python -m PyInstaller --noconfirm Anllm.spec`。不要沿用旧 ICO，否则程序和安装包仍会出现旧颜色。生成接口会随程序打包，运行版不需要再次生成或安装依赖。
3. 使用同一环境运行 `python -m playwright install chromium`，把安装得到的 Chromium 浏览器目录复制到 `dist/Anllm/_internal/browsers`，保留 `chromium-1243/chrome-win64/chrome.exe` 的目录层级。
4. 创建与 `Anllm` 文件夹同级的 `outputs` 目录，在其中放置 `Anllm使用说明.md`（内容来自源码根部的 `使用说明.md`），再运行 `python prepare_distribution.py` 和 `python make_portable.py`。安装包、便携包和源码包都会写入这个 `outputs` 目录。
5. 安装 Inno Setup 6.7.3，运行 `ISCC.exe Anllm.iss`，生成安装包。

校验时，把 `ANLLM_DATA_DIR` 设置为一个全新、可写的测试目录，避免操作真实会话。运行 `dist/Anllm/Anllm.exe --verify-package` 和 `--verify-tasks`；两个命令分别把结果写入测试目录的 `logs/package-verification.json` 与 `logs/task-list-verification.json`。

`--verify-tray` 校验关闭收起、后台任务继续、托盘恢复、请求通知和安全退出，结果写入 `logs/tray-verification.json`。在 Windows 桌面环境运行，并设置 `ANLLM_EXPECT_NATIVE_TRAY=1`，可要求真实系统托盘可用。`--verify-images` 与 `--verify-requests` 分别验证图片输入和请求显示。

`--verify-multitask` 验证真实 Qt 执行线程并行运行、草稿和事件归属、非模态权限请求、单独和全局停止、同文件备份一致性与桌面控制归属。`--verify-reasoning` 验证模型原生档位、请求体、思考与工具循环的原生上下文及每任务每模型的选择持久化。两项使用本地模拟数据，结果分别写入 `logs/multitask-verification.json` 与 `logs/reasoning-verification.json`。

`--verify-desktop` 在真实 Windows 桌面会话中创建独立测试窗口，实际验证截图、控件识别、窗口切换、中文输入、鼠标操作、拒绝与停止、Agent 观察—操作—复核循环。只操作测试程序，模型路由使用模拟客户端，不连接付费服务；结果为 `logs/desktop-verification.json`。不要与其他抢前台焦点的界面测试同时运行。`--verify-stop-shortcut` 验证全局快捷键注册、原生消息触发与退出释放，结果为 `logs/stop-shortcut-verification.json`。

源码目录里的 `check_core.py`、`check_profiles.py`、`check_multimodal.py`、`check_extensions.py`、`check_tasks.py` 可分别验证核心工具、多 API、跨模型路由、浏览器与协作，以及任务管理。每个校验使用独立数据目录。多 API 与跨模型校验使用本地模拟接口，不会发起真实服务商的付费请求。



`--verify-window-style` 在 Windows 桌面验证无系统标题栏、窗口按钮、关闭到托盘、确认取消行为、文件选择界面、透明圆弧外角与任务栏应用标识；结果为 `logs/window-style-verification.json`。`window_chrome.py` 统一窗口控件和弹窗外观，保留原有内部金色边框。
