# Anllm 的第三方组件

Anllm 的独立发行包使用以下开源组件。组件的许可、声明和浏览器资源保留在 `_internal` 与本文件夹的许可目录中。

- HKUDS/OpenHarness 0.1.9：MIT；源码：https://github.com/HKUDS/OpenHarness
- Python 3.11：Python Software Foundation License；源码：https://www.python.org/downloads/source/
- PySide6 / Qt 6：LGPL v3 与相关第三方许可；源码和版本：https://download.qt.io/official_releases/QtForPython/ 与 https://download.qt.io/archive/qt/
- Playwright：Apache 2.0；源码：https://github.com/microsoft/playwright
- comtypes 1.4.17：MIT；源码：https://github.com/enthought/comtypes 。用于调用 Windows 自带的 UI Automation 接口。
- Chromium / Chrome for Testing：BSD 风格许可及相关第三方许可；源码：https://chromium.googlesource.com/chromium/src/ ，许可证见附带浏览器的资源文件。
- PyInstaller：GPL v2，含允许分发应用程序的 bootloader exception；源码：https://github.com/pyinstaller/pyinstaller
- 其余 Python 依赖的声明见许可目录及随包的 `.dist-info`。

Qt / PySide6 以独立动态库形式置于 `_internal/PySide6` 和 `_internal/shiboken6` 中，可替换为相同接口的修改版本；请保留兼容的 ABI 和架构。Anllm 源代码及构建脚本随独立源码包提供。
