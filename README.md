# Anllm

**把想法写下来，让 AI 帮你处理项目、浏览网页和操作桌面。**

Anllm 是一款面向 Windows 的原生 AI 桌面助手。它把模型对话、文件工具、浏览器操作、桌面控制、视觉分析与图片创作放在同一个工作空间里。你可以选择自己的 API 和模型，用自然语言描述目标，并在任务工作台中查看执行过程和文件变化。

当前版本：**v1.4** · 平台：**Windows 10 / 11 x64** · 界面：**Python + PySide6 / Qt**

## 项目特点

### 多 API 与模型协作

- 保存多套 API 配置，为不同任务选择不同服务和模型。
- 支持 OpenAI 兼容接口、Chat Completions、Responses，以及 Claude 原生 Messages 接口。
- 从服务读取模型列表，支持筛选与切换。
- 主模型、视觉模型和生图模型可以分别配置，让文字模型也能调用看图与图片创作工具。
- 按模型能力提供思考强度选项，并分别记住每个任务、每个模型的选择。

实际可用模型、工具调用能力和思考档位取决于所接入的服务。

### 多任务并行，切换不中断

- 一个任务执行时，可以切换到其他任务，或启动新的任务。
- 草稿、回复、工具记录和执行状态按任务分别保存。
- 支持并行助手分工处理任务，由主 Agent 汇总结果。
- 支持任务收藏、排序与历史恢复；运行中的任务受到删除保护。

多个任务可以并行处理文件和对话。鼠标键盘操作由一个任务持有，避免同时争抢桌面控制。

### 从项目文件到桌面软件

| 能力 | 可以做什么 |
| --- | --- |
| 文件工具 | 查找、读取、搜索、创建和修改项目文件；查看文件工具记录的差异、备份并撤销相应修改。 |
| 命令执行 | 在权限规则允许的范围内运行命令，完成项目检查与开发任务。 |
| 浏览器 | 使用独立 Chromium 浏览器打开页面、读取内容、填写表单、点击与滚动，并查看页面预览。 |
| 桌面控制 | 观察窗口与控件，切换普通 Windows 软件，执行鼠标点击、拖动、滚动、文字输入与组合键。 |
| 视觉分析 | 理解参考图、项目图片，以及所属任务的浏览器和桌面截图。 |
| 图片创作 | 通过配置的图片服务生成图片，或使用参考图进行编辑。 |

桌面操作结合 Windows UI Automation 与截图观察，按“观察 → 操作 → 复核”的方式执行。系统安全桌面、UAC 和管理员窗口仍受 Windows 权限限制。

### 图片输入更自由

- 支持选择文件、拖入图片和粘贴截图。
- 支持只发送图片，无需额外输入文字。
- 不设置应用层的附图数量上限，按所选能力传递参考图。
- 图片在后台导入，附件栏支持横向滚动与缩略图预览。

单张参考图文件需小于 25 MB；模型服务仍可能限制图片数量、请求大小和上下文长度。

### 请求说明清楚，操作可以停止

- 提供只读、标准与完全访问三档权限。
- 标准模式下，程序识别的常规项目查询及部分简单操作自动执行。
- 需要确认时，先说明要做什么、为什么需要、执行位置和可能影响；原始参数放在折叠详情中。
- 模型缺少必要信息时，可以提出中文问题，提供建议答案或接受自定义回答。
- 可停止当前任务；使用 **Ctrl+Alt+F10** 或托盘菜单可停止全部运行任务。

文件工具限制在所选项目范围内。命令使用当前 Windows 用户权限执行，权限档位不等同于操作系统沙箱。

### 原生界面与按需加载

- 使用 Qt 原生桌面界面，日常交互不依赖网页外壳。
- 珍珠白与金色为主色，搭配紫色蔷薇、古典文学图案和钢琴装饰。
- 支持中央对话区自定义壁纸与遮罩。
- v1.4 移除系统白色标题栏，保留内部金色边框，采用平滑圆弧外角和融入主题的窗口按钮。
- 关闭窗口收起到系统托盘，后台任务继续执行；可从托盘恢复或退出。
- 浏览器与桌面组件按需启动；缩略图使用有上限的缓存，历史消息分批显示，减少重复加载与绘制。
- 桌面截图按需获取，不持续录屏；浏览器关闭最后一个页面后释放运行时资源。

## 快速开始

1. 从仓库 **Releases** 页面下载安装包或便携包。
2. 安装版按向导安装；便携版解压到可写目录后运行 `Anllm.exe`，并保留整个运行目录。
3. 打开 **API 与模型设置**，填写 API 地址与密钥，连接并读取模型，然后保存配置。
4. 按需配置视觉与生图服务，选择项目文件夹。
5. 在 **Agent** 模式下描述任务，或切换到对话、生图模式。

发行包自带 Python、Qt、Agent 依赖和 Chromium，无需另外安装开发环境。模型服务需要使用者自行配置，相关请求由所选服务计费。

## 本地数据与模型请求

API 配置、会话、参考图、生成图片、文件备份和浏览器缓存保存在本机。对话内容、工具结果，以及需要分析的图片或截图会按任务发送给所配置的模型服务。

公开发行包不包含使用者的 API 密钥、会话或项目文件。安装升级保留个人配置和会话；卸载不主动清除使用后产生的个人数据。

## 开发与构建

源码使用 Windows x64、Python 3.11 和 PySide6。构建依赖版本、UI Automation 接口生成、浏览器打包和安装包生成步骤见 [源代码构建](packaging/源代码构建.md)。

```text
desktop/                       应用源码、界面资源与验证模块
  main.py                      主界面、任务切换与交互
  core.py                      Agent、文件工具与 API 适配
  settings_panel.py            API、模型、权限及外观设置
  window_chrome.py             窗口按钮、圆角弹窗与任务栏标识
  theme.py                     主题与界面样式
  browser_bridge.py            浏览器操作
  desktop_control.py           桌面工具与控制流程
packaging/                     依赖、构建脚本与安装包配置
使用说明.md                    完整功能与操作说明
思考强度适配说明.md             模型思考强度适配说明
```

程序提供多任务、权限请求、图片输入、系统托盘、窗口样式等离线验证入口。验证方法见构建文档。
